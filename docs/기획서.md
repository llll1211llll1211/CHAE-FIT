채피티** **(chafit)** **추가** **기능** **기획서**

_이력서_ _기반_ _직무_ _적합도_ _진단_ _및_ _채용공고_ _매칭_ _서비스_ _—_ _기능_ _확장안_

1. 문서 목적
   ========

본 문서는 현재 개발 중인 채피티(chafit) 서비스의 1단계(이력서 업로드) 프론트엔드가 구현된 상태에서, 이후 추가되어야 할 핵심 기능들을 정의하고 우선순위를 정리하기 위해 작성되었습니다.

타겟 사용자는 산업/직무 방향은 이미 정했으나, 본인의 경험(프로젝트, 인턴, 자격증 등)이 실제로 그 분야 기업이 원하는 역량과 맞는지 확신이 없는 취업준비생 및 직무 전환 희망자입니다.

2. 현재 구현 상태
   ===========

•     이력서 업로드 화면 (PDF/TXT,5MB 이하) — 완료

•     파일 유효성 검사 (확장자, 용량) — 완료

•     분석 요청 API 연동 구조 (/api/resume/analyze) — 프론트엔드 구조만 완료, 백엔드 미구현

•     분석 결과 화면 (AnalysisSummary,RoleRecommendations) — 미구현

3. 타겟 사용자 (업데이트)
   ================

| **구분** | **내용**                                                                          |
| ------ | ------------------------------------------------------------------------------- |
| 페르소나 A | 신입 지원자 — 가고 싶은 산업/직무는 정했지만, 본인 활동(프로젝트, 인턴 경험)이 실제로 그 분야 기업이 원하는 역량과 맞는지 확신이 없음 |
| 페르소나 B | 직무 전환 희망자 — 목표 산업/직무는 정했지만, 기존 경력이 그 분야에서 얼마나 통할지 판단이 서지 않음                     |

4. 추가 기능 목록
   ===========

**4-1.** **기업별** **적합도** **진단서 (****핵심** **기능)**

•     특정 기업의 채용공고 URL 또는 텍스트를 입력하면, 업로드한 이력서와 비교하여 적합도 점수와 부족한 부분을 리포트 형태로 생성

•     적합도 산출 근거를 문장으로 함께 제시 (예: 'PECVD 프로젝트 경험이 요구 역량 중 공정 데이터 분석과 direct 매칭')

•     우선순위: 최우선 · 난이도: 중

**4-2.** **채용공고** **자동** **요약**

•     긴 채용공고 텍스트를 업로드/붙여넣기하면 핵심 자격요건, 우대사항을 3줄 내외로 요약

•     적합도 진단서 기능의 입력 전처리 단계로도 활용 가능

•     우선순위: 높음 · 난이도: 하 (MVP에 빠르게 추가 가능)

**4-3.** **자소서** **문항별** **근거** **매핑**

•     자소서 문항(예: '지원 동기는 무엇인가요')을 입력하면, 이력서 내 경험 중 어떤 것을 어떻게 연결하면 좋을지 문장 초안을 제안

•     AI 대필 논란 방지를 위해 결과에 '초안' 라벨을 명시하고, 사용자가 직접 수정하는 구조로 설계

•     우선순위: 중 · 난이도: 중

**4-4.** **직무** **요구사항** **대비** **경쟁력** **비교**

•     목표 직무의 일반적 요구 스펙 대비 본인의 현재 위치를 시각화

•     또래 비교가 아닌 '직무 요구사항 대비'로 한정하여 동조 심리 자극을 방지

•     우선순위: 중 · 난이도: 중

**4-5.** **관심** **기업** **북마크** **및** **적합도** **트래킹**

•     관심 기업 여러 곳을 저장해두고, 경험을 추가할 때마다 각 기업 적합도 변화를 확인

•     '이 활동을 하면 A기업 적합도가 오른다'는 형태로 동기부여 제공

•     우선순위: 낮음 · 난이도: 중 (계정/저장 기능 필요)

**4-6.** **갭** **리포트 →** **활동** **추천** **연결**

•     적합도 진단 결과에서 나온 부족한 역량을 기반으로, 보완 가능한 비교과 활동을 근거와 함께 추천

•     1회성 진단이 아닌 '진단 → 보완 → 재진단'의 순환 구조로 확장

•     우선순위: 낮음 (해커톤 이후 확장 기능) · 난이도: 상

5. 우선순위 로드맵
   ===========

| **단계**       | **기능**               | **목적**       | **비고**          |
| ------------ | -------------------- | ------------ | --------------- |
| MVP 핵심       | 이력서 분석 + 기업별 적합도 진단서 | 해커톤 메인 데모 기능 | 최우선 개발          |
| MVP 보조       | 채용공고 자동 요약           | 입력 편의성 향상    | 난이도 낮아 빠른 추가 가능 |
| 확장 (시간 허용 시) | 자소서 문항 매핑 / 경쟁력 비교   | 발표 임팩트 강화    | 데모 시나리오에 포함 검토  |
| 장기 확장        | 북마크/트래킹, 갭리포트 순환구조   | 서비스 지속 사용 유도 | 해커톤 이후 로드맵      |

6. 검토 필요 사항
   ===========

•     적합도 진단서 산출 로직: 채용공고 텍스트와 이력서 텍스트를 Claude API에 어떤 프롬프트 구조로 전달할지 개발팀과 협의 필요

•     데이터 소스: 워크넷/공공데이터포털(국내), Adzuna(해외) API 연동 범위 확정 필요

•     자소서 문항 매핑 기능의 AI 대필 논란 리스크 — '초안' 라벨링 UX 방식 구체화 필요
